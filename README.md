# Pizza_hut
Project Overview
This project focuses on analyzing Pizza Hut sales data using MySQL to extract meaningful business insights.
The analysis answers real-world business questions related to orders, revenue, customer preferences, and sales trends, making it suitable for Data Analyst, MIS Executive, and Business Analyst roles.
🎯 Objectives
The main goals of this project are:
Analyze overall sales performance
Identify best-selling pizzas and categories
Understand customer ordering patterns
Evaluate revenue contribution by pizza type and category
Perform time-based sales analysis
🛠️ Tools & Technologies
Database: MySQL
Language: SQL
Concepts Used:
Joins
Aggregate Functions
Group By & Having
Subqueries
Date & Time Functions
Window Functions (for cumulative revenue)
🗂️ Dataset Description
The dataset consists of multiple relational tables, including:
orders – order date & time
order_details – quantity per order
pizzas – pizza size & price
pizza_types – category & name
This structure simulates a real restaurant POS database, commonly used in analytics case studies.
🔍 Key SQL Analysis Performed
The project answers the following business questions:
Total number of orders placed
Total revenue generated from pizza sales
Highest-priced pizza
Most commonly ordered pizza size
Top 5 most ordered pizza types by quantity
Total quantity ordered per pizza category (using joins)
Order distribution by hour of the day
Category-wise pizza distribution
Average number of pizzas ordered per day
Top 3 pizza types based on revenue
Percentage contribution of each pizza type to total revenue
Cumulative revenue generated over time
Top 3 revenue-generating pizzas for each category
📈 Insights Generated
Identified best-selling pizzas and sizes, helping optimize inventory
Discovered peak ordering hours, useful for staffing decisions
Analyzed revenue-driving categories, aiding menu optimization
Tracked revenue growth trends over time
